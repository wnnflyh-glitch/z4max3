# 🟦 Cloning System

**Overview**

The **Cloning System** in Zone4 is designed to separate an item’s **Appearance** from its **Stats**.

Players can transfer the stats from one item to another, allowing them to wear visually appealing outfits while keeping the best possible stats at the same time.

This system provides greater flexibility in character customization.

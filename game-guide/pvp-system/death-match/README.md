# Death Match

### Overview

**Death Match** is a core PvP mode in Zone4 where players compete in an arena to score points by defeating opponents.

This mode is divided into two types:

* **Team Death Match**
* **Single Death Match**

Both modes share the following features:

* Supports **1–8 players**
* Can start with a minimum of **1 vs 1**
* Match duration options: **3 minutes or 5 minutes**
* Includes an **MVP (Most Valuable Player)** system to evaluate player performance

In Death Match, the **Room Host** can customize additional gameplay rules before the match begins to control how the game is played.

**Key configurable options include:**

* **E Special Toggle**
* **Item Usage Toggle**

### Item Usage System

In certain PvP matches, players can use **Special Items** during combat.

These items may provide:

* **Damage Buff (x2)**
* **HP/SP Recovery Boxes**
* **Utility effects**

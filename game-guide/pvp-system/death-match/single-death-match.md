# Single Death Match

Overview

**Single Death Match** is a Free-for-All PvP mode where all players fight against each other with no teams.

**Number of players:**

```
1 – 8 Players
```

Minimum players required to start the match:

```
1 vs 1
```

***

## Match Duration

เหมือนกับ Team Death Match

| Match Time | Description    |
| ---------- | -------------- |
| 3 Minutes  | Short Match    |
| 5 Minutes  | Standard Match |

***

## Scoring System

Players earn points by defeating other players.

```
Player Kill = +1 Point
```

Example scoreboard:

| Rank | Player   | Score |
| ---- | -------- | ----- |
| 1    | Player A | 35    |
| 2    | Player B | 33    |
| 3    | Player C | 21    |

The player with the highest score when time runs out will be the winner.

***

## Tie-Break Rule

**If the 1st and 2nd place players have the same score:**\
**Example:**

```
Rank 1 = 35
Rank 2 = 35
```

The system will use the **MVP Player** as the tiebreaker.

**Rules:**

```
ผู้เล่นที่ได้รับ MVP → ชนะทันที
```

**Example:**

| Player   | Score | MVP |
| -------- | ----- | --- |
| Player A | 35    | ✓   |
| Player B | 35    | -   |

**summary:**

```
Player A Win
```

***

## MVP System

### Overview

**MVP (Most Valuable Player)** is a system used to evaluate the best-performing player in a match.

MVP is not determined by kills alone, but is calculated based on multiple factors.

***

### MVP Calculation Factors

The factors used to calculate MVP are:

| Factor       |
| ------------ |
| Damage Dealt |
| Kill Count   |

The system will calculate a **Performance Score**, and the player with the highest score will be awarded **MVP**.

***

## Gameplay Impact of MVP

**MVP Roles**

The MVP system plays an important role in the game:

**1. Tie-break Decision**\
Used to determine the winner in case of a tie

**2. Player Recognition**\
Highlights the best-performing player in the match

**3. Performance Rewards**\
Some systems may grant:

* EXP bonus
* Zen bonus

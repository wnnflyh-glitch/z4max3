# Rush Class

**Rush Class (Grappler Fighter)**

Rush is a combat class focused on:

* Grabbing
* Locking
* Throwing
* Controlling the opponent’s position

The Rush class can grab opponents even while they are airborne and deal high damage through powerful throw attacks.

**Strengths:**

* High grab damage
* Strong crowd control
* Can break enemy combos

**Weaknesses:**

* Slower movement speed
* Shorter combo chains

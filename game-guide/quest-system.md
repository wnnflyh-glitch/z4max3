# ❔ Quest System

### **Overview (ภาพรวมระบบ)**

ระบบ **Quest (ภารกิจ)** ในเกม Zone4 เป็นหนึ่งในระบบหลักที่ใช้ในการ:

* นำทางผู้เล่นผ่านเนื้อหาเกม
* สร้างโครงสร้างการเล่น (Gameplay Flow)
* มอบรางวัลและแรงจูงใจให้ผู้เล่น

***

### **โครงสร้างของ Quest (Quest Structure)**

Quest หนึ่งรายการประกอบด้วยองค์ประกอบหลักดังนี้:

#### **Quest Title (ชื่อเควส)**

* แสดงชื่อภารกิจ เช่น\
  → “หาประสบการณ์ใน Arcade”

#### **Objective (เป้าหมายภารกิจ)**

สิ่งที่ผู้เล่นต้องทำ เช่น:

* เข้าเล่นโหมด Arcade
* กำจัดศัตรู
* เคลียร์ดันเจี้ยน
* คุยกับ NPC

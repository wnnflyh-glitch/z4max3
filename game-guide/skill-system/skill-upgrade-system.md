# Skill Upgrade System

### Overview <a href="#overview" id="overview"></a>

The **Skill Enhancement System** allows players to improve the effectiveness of the skills they own by upgrading them from **Lv.0 → Lv.10**.

Upgrading a skill will increase:

* Skill damage
* Attack efficiency

This system includes a **risk mechanic**, meaning upgrades can either **succeed or fail**.

**Upgrade Resources**\
The system uses the following main resources:

| Resource             | Function           |
| -------------------- | ------------------ |
| Skill Upgrade Coupon | Used for upgrading |
| ZEN                  | fee                |
| Zeed Blessing        | Token              |

**Skill Upgrade System**\
Players can upgrade skills to increase:

* **Damage %**

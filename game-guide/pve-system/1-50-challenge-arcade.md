# 1-50 Challenge Arcade

## 1-50 Challenge Arcade

**Challenge Arcade** is a solo PvE survival progression mode designed to test players’ skills across **50 consecutive stages**.

It features systems such as **Difficulty Scaling**, **Limited Lives**, and **Reward Scaling** to create a challenging experience and provide competitive motivation through the **Daily Ranking System**.

Players must battle increasingly difficult NPC Fighters as they progress, reaching up to **Stage 50**, which is the highest level in the system.

### Entry System <a href="#entry-system" id="entry-system"></a>

<figure><img src="../../.gitbook/assets/2.gif" alt=""><figcaption></figcaption></figure>

#### Entry Condition <a href="#entry-condition" id="entry-condition"></a>

Players can enter Challenge Arcade multiple times per day.

| Entry Count | Entry Fee |
| ----------- | --------- |
| 1 – 2       | Free      |
| 3           | 1000 Zen  |
| 4           | 2000 Zen  |
| 5           | 3000 Zen  |

The entry cost increases with each additional run within the same day.

***

### Core Combat System <a href="#core-combat-system" id="core-combat-system"></a>

#### Player Objective <a href="#player-objective" id="player-objective"></a>

Defeat NPC fighters to progress through as many stages as possible.

***

#### Enemy Structure <a href="#enemy-structure" id="enemy-structure"></a>

Enemies are designed with the following characteristics:

| Attribute   | Description                                   |
| ----------- | --------------------------------------------- |
| Class       | Martial Art Class (Muay Thai, Taekwondo etc.) |
| Skill Set   | Combo Skill + Special Skill                   |
| AI Behavior | Aggressive / Defensive                        |
| Scaling     | Damage + HP Increase                          |

#### Healing System <a href="#healing-system" id="healing-system"></a>

There is no HP recovery system between stages.

```
No Healing Item
No HP Pickup
No Recovery Box
```

***

### Difficulty Scaling <a href="#difficulty-scaling" id="difficulty-scaling"></a>

**Scaling Parameters**

| Parameter     | Scaling                 |
| ------------- | ----------------------- |
| Enemy HP      | Increase per stage      |
| Enemy Damage  | Increase per stage      |
| Enemy Count   | Increase after stage 30 |
| AI Aggression | Increase late stages    |

***

#### Difficulty Phases <a href="#difficulty-phases" id="difficulty-phases"></a>

| Stage | Difficulty Tier |
| ----- | --------------- |
| 1–10  | Tutorial PvE    |
| 11–20 | Normal          |
| 21–30 | Advanced        |
| 31–40 | Expert          |
| 41–50 | Extreme         |

***

## Ranking System



Challenge Arcade ใช้ระบบ **Daily Ranking**

<figure><img src="../../.gitbook/assets/image (113).png" alt=""><figcaption></figcaption></figure>

Ranking is calculated based on:

```
Ranking Score = Stage Cleared + Clear Time
```

{% hint style="info" %}
Ranking resets Weekly
{% endhint %}

***

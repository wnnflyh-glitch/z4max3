# Hidden Arcade

## Hidden Arcade

Hidden Arcade, also known by players as “Joker,” is a secret PvE mode in Zone4. It becomes available when players achieve high performance in Normal Arcade.

**Key condition:**

> Players must successfully clear Normal Arcade and achieve a **Rank S or higher based on completion time**.

Once this condition is met, access to Hidden Arcade is guaranteed.

### Unlock Condition <a href="#unlock-condition" id="unlock-condition"></a>

#### Core Requirement <a href="#core-requirement" id="core-requirement"></a>

Players must meet two conditions.

| Requirement         | Description               |
| ------------------- | ------------------------- |
| Clear Normal Arcade | ผ่านด่านสุดท้ายของ Arcade |
| Rank Requirement    | ได้ S Rank หรือสูงกว่า    |

#### Rank Calculation <a href="#rank-calculation" id="rank-calculation"></a>

Rank is calculated based on:

* Clear Time

**Rank Example Model**

Rank Score = Time Score

| Rank | Requirement |
| ---- | ----------- |
| F    | Fail        |
| C    | Clear Stage |
| B    | Normal      |
| A    | Fast        |
| S    | Very Fast   |

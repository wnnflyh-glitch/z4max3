# Gang Create

## Gang Create (Registration Certificate)

<figure><img src="../../.gitbook/assets/1773314547247.gif" alt=""><figcaption></figcaption></figure>

**Required Fields**

**1️⃣ Club Name**

* The main Gang name
* English characters only
* Maximum of 14 characters

**2️⃣ Club Nick**

* Gang abbreviation (Tag)
* Displayed in front of the character’s name
* Maximum of 14 characters

**3️⃣ Emblem**

* Gang logo
* File format must be **.TGA**
* Size: **32x32 pixels**
* File size must not exceed **4KB**

**How to Use the Emblem**\
Place the file in the designated folder.

```
Zone4/Emblem
```

Enter the file name, for example:

```
basic.tga
```

Once all fields are completed, click **Registration Completed**.

The Gang will be created immediately, and the creator will become the **Gang Master**.

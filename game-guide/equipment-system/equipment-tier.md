# Equipment Tier

## Equipment Tier

Zone4 uses an **Item Tier / Grade system** to determine the rarity and power of equipment. The general tier structure is as follows:

| Tiers    | Colors |
| -------- | ------ |
| Low      | Black  |
| Normal   | Gray   |
| High     | Green  |
| Unique   | Blue   |
| Rare     | Yellow |
| Legend   | Orange |
| Ultimate | Pink   |

Tier affects:

* Stats base
* Visual effect

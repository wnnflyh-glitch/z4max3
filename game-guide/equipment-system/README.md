# 🎽 Equipment System

### Overview

The **Equipment System** in Zone4 is used to:

* Increase combat stats
* Change the character’s appearance
* Create unique character builds

This system is a **core progression system** of the game. Players can:

* Equip items in multiple slots simultaneously
* Build their character based on their playstyle

Zone4 uses a **Stat-based Equipment Enhancement system**, meaning every piece of equipment provides stat bonuses to the character.

***

# Gang War Resgisteration

## Overview

The **Gang War Registration System** is a team-based competitive system (Gang PvP) in Zone4, designed for players to form Gangs and participate in **Team Tournaments**.

Gangs that wish to participate must:

* Register their fighters (members)
* Register **Club Silver Coins**
* Meet the minimum requirements before the competition

The system will select the **top 16 Gangs with the highest Contribution** to enter the tournament stage.

***

### **Gang Fighter Registration System**

\
**Registration Rules**

| Parameter                            | Value       |
| ------------------------------------ | ----------- |
| Maximum number of registered members | 20          |
| Number of actual participants        | 16          |
| Registered players                   | Gang Leader |

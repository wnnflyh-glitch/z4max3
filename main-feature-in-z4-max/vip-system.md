# 👑 VIP System

## **Overview**

**VIP System** is a premium subscription model that players can purchase to instantly unlock exclusive benefits.

**VIP Activation**\
Players can access the VIP menu to activate their VIP status.

<figure><img src="../.gitbook/assets/VIP System.gif" alt=""><figcaption></figcaption></figure>

```
EVENT → VIP
```

The system will then display the status.

<figure><img src="../.gitbook/assets/image (124).png" alt="" width="563"><figcaption></figcaption></figure>

```
You are not a VIP member yet
```

Players can click **Purchase** to buy VIP.

<figure><img src="../.gitbook/assets/VIP 2.gif" alt=""><figcaption></figcaption></figure>

```
Purchase
```

***

**VIP Privileges**

When VIP is activated, players will receive the following benefits:

**Stats Bonus**

* **All Stats +30**: Increases all character attributes

**EXP / Zen Bonus**

* **EXP / ZEN +10%**: Players will receive increased EXP and ZEN gains

| Resource | Bonus |
| -------- | ----- |
| EXP      | +10%  |
| Zen      | +10%  |

**Special Storage**\
VIP players will receive additional special storage slots.

**NPC Discount**

* **10% Special Discount (NPC Yuki):** VIP players receive a 10% discount when purchasing items from NPC Yuki.

**Daily Potion**

* **HP/SP Potions x50 daily:** VIP players will receive 50 HP/SP potions every day.

| Item      | Amount |
| --------- | ------ |
| HP Potion | 50     |
| SP Potion | 50     |

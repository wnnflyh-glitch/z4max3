# Copy of Death Match

### Overview

**Death Match** is a core PvP mode in Zone4 where players compete in an arena to score points by defeating opponents.

This mode is divided into two types:

* **Team Death Match**
* **Single Death Match**

Both modes share the following features:

* Supports **1–8 players**
* Can start with a minimum of **1 vs 1**
* Match duration options: **3 minutes or 5 minutes**
* Includes an **MVP (Most Valuable Player)** system to evaluate player performance

In Death Match, the **Room Host** can customize additional gameplay rules before the match begins to control how the game is played.

**Key configurable options include:**

* **E Special Toggle**
* **Item Usage Toggle**

***

### Item Usage System

In certain PvP matches, players can use **Special Items** during combat.

These items may provide:

* **Damage Buff (x2)**
* **HP/SP Recovery Boxes**
* **Utility effects**

## Team Death Match

### Overview

**Team Death Match** is a mode where players are divided into two teams.

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/1773125983802.gif" alt=""><figcaption></figcaption></figure></div>

```
Red Team
Blue Team
```

Each team can have up to **4 players**,\
so the maximum number of players in a room is **8**.

```
8 Players (4 vs 4)
```

The minimum requirement to start a match is:

```
1 vs 1
```

***

## Match Duration

The Room Host can select the match duration.

| Match Time | Description    |
| ---------- | -------------- |
| 3 Minutes  | Short Match    |
| 5 Minutes  | Standard Match |

When the time

```
Timer = 0
```

ช่วยแปลเป็นภาษาอังกฤษเพื่อ สื่อสารกับผู้เล่น

***

## Scoring System

The team’s score increases when defeating opposing players.

```
Enemy Kill = +1 Team Point
```

Example Scoreboard

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/1773126568836.gif" alt="" width="563"><figcaption></figcaption></figure></div>

| Team      | Score |
| --------- | ----- |
| Red Team  | 21    |
| Blue Team | 11    |

{% hint style="info" %}
The team with the highest score when time runs out will be the winner.
{% endhint %}

***

## Tie-Break Rule

**In case of a tie:**\
**Example:**

```
Red Team = 35
Blue Team = 35
```

The system will use the **MVP Player** as the tiebreaker.

**Rules:**

<pre><code>The team that has the <a data-footnote-ref href="#user-content-fn-1">MVP player</a> → that team wins.
</code></pre>

ตัวอย่าง

| MVP Player | Team     |
| ---------- | -------- |
| Player A   | Red Team |

ผลลัพธ์

```
Red Team Win
```

## Scoring System

ผู้เล่นจะได้รับคะแนนเมื่อกำจัดผู้เล่นคนอื่น

```
Player Kill = +1 Point
```

ตัวอย่าง scoreboard

| Rank | Player   | Score |
| ---- | -------- | ----- |
| 1    | Player A | 35    |
| 2    | Player B | 33    |

***

## Tie-Break Rule

หากผู้เล่นอันดับ 1 และ 2 มีคะแนนเท่ากัน

ตัวอย่าง

```
Rank 1 = 35
Rank 2 = 35
```

ระบบจะใช้ **MVP Player** เป็นตัวตัดสิน

กติกา

```
ผู้เล่นที่ได้รับ MVP → ชนะทันที
```

ตัวอย่าง

| Player   | Score | MVP |
| -------- | ----- | --- |
| Player A | 35    | ✓   |
| Player B | 35    | -   |

ผลลัพธ์

```
Player A Win
```

## MVP System

### Overview

MVP (Most Valuable Player) เป็นระบบที่ใช้ประเมิน **ผู้เล่นที่มีผลงานดีที่สุดในแมตช์**

MVP ไม่ได้วัดจาก kill เพียงอย่างเดียว

แต่คำนวณจากหลายองค์ประกอบ

***

### MVP Calculation Factors

องค์ประกอบที่ใช้คำนวณ MVP เช่น

| Factor       | Description   |
| ------------ | ------------- |
| Damage Dealt | ดาเมจที่ทำได้ |
| Kill Count   | จำนวน kill    |

ระบบจะคำนวณ **Performance Score**

ผู้เล่นที่มีคะแนนสูงสุดจะได้รับ MVP

***

## Gameplay Impact of MVP

MVP มีบทบาทสำคัญในระบบ

#### 1. Tie-break decision

ใช้ตัดสินผู้ชนะในกรณีคะแนนเท่ากัน

***

#### 2. Player Recognition

แสดงผู้เล่นที่มีผลงานดีที่สุด

***

#### 3. Performance Reward

บางระบบอาจให้

* EXP bonus
* Gold bonus

# Street Class

**Street Class (Striking Fighter)**

Street is a combat class focused on:

* Close-range attacks
* Using punches and kicks
* Performing continuous combo chains
* Juggling enemies in the air

The Street class is designed to deal sustained damage through combo attacks and control the battlefield with constant pressure.

**Strengths:**

* Long combo chains
* Consistent damage output
* Well-suited for PvP

**Weaknesses:**

* Lacks grab control
* Vulnerable when caught by grabs

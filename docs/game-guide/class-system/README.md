# 🤼 Class System

### Overview

The **Class System** in Zone4 is designed as a **Martial Arts–Based Class System**, where each class is inspired by real-world fighting styles.

Players can choose a **Base Class**, and upon reaching a certain level, they can advance into an **Advanced Class** with unique combat mechanics.

This system adds depth and variety to the game in terms of:

* Playstyle
* Combo Mechanics
* PvP Strategy
* Skill Expression

In Zone4, there are **2 main Base Classes**:

* **Street (Striking Type)**
* **Rush (Grappler Type)**

These can further evolve into **8 main Fighting Styles**.

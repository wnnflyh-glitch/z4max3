# 🦸‍♂️ Character System

## **Overview**

All characters use the same stat structure.\
Therefore, characters are not restricted to specific roles such as:

* Tank
* DPS
* Support

***

***

**Character Stat Framework**

All characters use the same Stat Model.\
Stats are divided into 4 categories:

* **Attack Stats**
* **Defense Stats**
* **Critical Stats**
* **Point Stats**

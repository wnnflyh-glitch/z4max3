# Normal Arcade

### Overview

**Normal Arcade** is a PvE Story Progression mode in Zone4, where players must fight against AI enemies across various stages to advance the storyline and unlock new areas.

This mode features:

> **Stage-based PvE Mode**

Players must:

* Fight enemies in each area
* Clear waves of monsters
* Defeat the stage boss

After completing a stage, players will have a chance to receive special rewards.

## Arcade Progression

## Difficulty Scaling

The difficulty of Arcade increases with each stage.

| Stage  | Difficulty  |
| ------ | ----------- |
| Park   | Easy        |
| Hotel  | Easy–Medium |
| Harlem | Medium      |
| H.Rose | Hard        |
| Subway | Very Hard   |

The increase in difficulty comes from:

* Enemy HP
* Enemy damage
* AI behavior

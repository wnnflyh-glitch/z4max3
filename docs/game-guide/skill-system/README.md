# 🤸‍♂️ Skill System

## Overview

The **Skill System** in Zone4 is a **Martial Arts Skill Equipment System** that allows players to collect skills and equip them into various slots.

Skills are categorized based on attack types, such as:

* **Crush**
* **Hold**
* **Special**
* **Team Double**
* **Misc**

Players can:

* Collect Skills
* Equip Skills
* Upgrade Skills

Skills can be upgraded from **Level 0 to Level 10**.

## Crush Skill System

**CRUSH** refers to a type of attack skill that focuses on powerful, direct strikes designed to deal heavy damage to the opponent.

> Main Combo

<figure><img src="../../.gitbook/assets/image (164).png" alt=""><figcaption></figcaption></figure>

Example:

* Strom Combo
* Whiplash Kick
* Double Spin Kick
* Swallow Mallet Elbow

#### CRUSH Mechanics

**CRUSH skill** is used for:

* Combo opener
* Combo chain
* Burst damage

***

## Hold Skill System

**HOLD** refers to a type of skill that focuses on grabbing, locking, or controlling the opponent, often leading into throws or follow-up attacks.

> Grab

<figure><img src="../../.gitbook/assets/image (165).png" alt=""><figcaption></figcaption></figure>

Used for:

* Break defense
* Crowd control

#### Hold Mechanics

When a **Hold** is successful, players can:

* **Throw**
* **Slam**
* Perform a **follow-up attack**

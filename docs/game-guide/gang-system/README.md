**Gang Roles (Example)**

* **Master**\
  The leader of the Gang\
  Has full management authority
* **Semi Master**\
  Vice leader\
  Has partial management permissions
* **Member**\
  Regular member

***

## Gang Role

Main role

| Role       |
| ---------- |
| Master     |
| SemiMaster |
| Member     |

The **Master** can:

* Invite members
* Remove members
* Change roles
* Edit Gang information

***

**Gang Level**

The Gang has its own level, which increases from:

* Gang PvP Rewards

**Example:**

```
Lv.1 → Lv.2 → Lv.3 ...
```

As the level increases:

* The maximum number of members will increase

***

**Gang PvP System**

The interface includes a **Gang PvP Record**, which is used to store:

* Gang battle data
* Match results

**Example:**

```
Win / Lose
Score
Opponent
```

#### **Keyboard Controls** <a href="#mouse-controls" id="mouse-controls"></a>

**Movement Controls**

Players navigate their character using the directional keys:

* **Arrow Keys (↑ ↓ ← →)**\
  Used for character movement: forward, backward, left, and right.

**Core Combat Controls**

* The primary combat system is built around four main keys:
  * **D — Attack**\
    Performs basic strikes (punches/kicks).
  * **S — Grab / Throw**\
    Initiates grapples and combo throws.
  * **A — Evasion / Defense**\
    Used for dodging or countering enemy attacks.
  * **F — Item Interaction**\
    Pick up, use, or throw items.

These keys form the foundation of all combat interactions and combo execution.

**Skill & Special Attacks**

* Players can execute advanced abilities using:
  * **Q — Special Skill 1**\
    Entry-level skill, often used to initiate combos.
  * **W — Special Skill 2**\
    Intermediate skill, typically used to extend combos.
  * **E — Ultimate Skill**\
    High-impact finishing move with significant damage.

**Interaction & Utility Controls**

* **Space Bar — Interaction**\
  Used to interact with NPCs and in-game objects.
* **ESC — Menu / Exit**\
  Opens the system menu or exits interfaces.

**Interface & System Shortcuts**

Players can quickly access key systems using the following shortcuts:

* **R — Map**
* **T — Events**
* **I — Inventory (Bag)**
* **P — Profile**
* **L — Quest Log**
* **C — Character Info (My Info)**
* **N — Club / Guild**
* **M — Messenger / Social**

These shortcuts improve navigation efficiency and reduce reliance on mouse input.

**Quick Slot System**

* **Keys 1–8 — Quick Slots**\
  Used to activate assigned items, consumables, or skills.

This allows players to react quickly during combat scenarios.

**System Functions & Miscellaneous**

* **F1 — Help Menu**
* **F2 — Town / Match Selection**
* **F10 — Toggle Fullscreen Mode**
* **F12 — Hide UI**
* **Print Screen — Screenshot Capture**
* **Shift — Modifier Key** (used for alternative actions or item switching)

#### **Mouse Controls** <a href="#mouse-controls" id="mouse-controls"></a>

The mouse controls the following actions in RO:

* Camera:
  * _Changing magnification_: Roll the mouse-wheel to zoom in and out. To do this without a mouse-wheel, hold the Ctrl key, right mouse button, and move the mouse Changing the overview.
* Character Interaction: Right-click another character and a window will pop up with a list of actions to choose from. Some options only appear under certain circumstances.
* Item/Skill Description: Right-click an item or skill and a window will pop up giving detailed information on that particular item or skill.
* Transferring items between active window: double-click an item in inventory to send it to active Storage window

***

#### Communication <a href="#communication" id="communication"></a>

To talk, type in the chat window and press Enter. What is said will be seen by everybody within a certain range. If Battle mode is on, the Enter key must be pressed before chatting.

Some notes on communication:

* To send a message to the party only, type /p Add a space, followed by the text.
* To send a message to the guild only, type /g Add a space, followed by the text.
* To PM another player, type /w Add a space, followed by the character name.
* To set 1:1 chat, go into friend set up and customize whether to open a new chat window or not.

#### Interaction With Others

\
To interact with other players, right-click on a character and choose an action from the list provided.

* Check (character name)'s Equipment Info — View the target players equipment if they have checked the "Open equipment" box on their equipment screen.
* Request a deal with (character name) — Allows trading items or ZEN with another character. After the target player accepts the offer to trade, the trade window will appear. Items can be dragged and dropped here for trading. ZEN can also be entered here for trading. Click "OK" and then "Trade" to confirm.
* Ask (character name) to join your party — Allows party leaders to invite characters into the party.
* Invite (character name) to Gang — If given the power to recruit players into the gang, this option allows recruiters to invite other characters into the gang. This power to recruit must be given by the gang master.
* Open 1:1 (Whisper) Chat — Allows talking to the character privately.
* Register as a Friend — Adds the character to the friends list.

#### Interaction with NPCs <a href="#interaction-with-npcs" id="interaction-with-npcs"></a>

NPCs are non-player characters. They are not real people but characters programmed into the game. To interact with an NPC, Spacebar on the target NPC.

Notable NPCs:

* Speaker Man — These NPCs are guides and can tell the location of important places in town.
* Yuki — These NPCs manage the shop. You can purchase items to enhance your gameplay experience.
* Momsen — These NPCs are responsible for managing the **Party System**. You can talk to them to get more information about it.
* Randy Heart — These NPCs are responsible for handling your class change.
* Blackrose — These NPCs are responsible for managing the **Zeed System**. You can talk to them to get more information about the system
* Franklin — These NPCs are responsible for managing the **Battle Pass system**. You can talk to them to get more information about it.

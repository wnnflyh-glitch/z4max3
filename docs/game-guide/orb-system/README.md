# ⚪ ORB System

#### Overview <a href="#overview" id="overview"></a>

The **ORB System** is an Enhancement / Socket System in Zone4 that allows players to insert **ORBs** into their character’s equipment to gain additional stat bonuses.

**Key Features:**

* Insert ORBs into Costumes
* ORB levels range from **+1 to +20**
* ORBs can be upgraded
* Provides additional stats to the character

This system is a **core progression system** of the game.

**Equipment Slot Structure**\
Character costumes can have up to **9 ORB slots**.

**Example Slots:**

| Hair   |
| ------ |
| Face   |
| Top    |
| Bottom |
| Shoes  |
| Gloves |
| Back   |
| Hat    |
| Ring   |

***

## ORB Levels

```
+1 → +20
```

The higher the level:

* Stats increase
* Rarity increases
* Value increases

***

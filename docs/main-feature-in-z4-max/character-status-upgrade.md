# ➕ Character Status Upgrade

## Overview

**Character Status Upgrade** is a new stat progression system in Zone4 that replaces the previous “character-locked stats” model with a customizable, build-your-own system. This allows all six characters to create diverse builds tailored to different playstyles, while ensuring fair competition in both PvE and PvP.

***

### Stat Model

This system is based on Zone4’s type-based stat system.

***

### Status Reset

<p align="center"><img src="../../.gitbook/assets/unknown (4).png" alt=""></p>

* Use the **Status Reset item (14,900 DE)** to reset all allocated stats
* Returning them to available Stat Points based on the total amount owned.

{% hint style="info" %}
The item can be purchased from the **DE Shop**.
{% endhint %}
